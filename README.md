# My First CV Website

A fully static CV website developed with pure HTML, CSS, and vanilla JavaScript.  
This project marks my starting point in frontend development.

---

## ⏳ Development Timeline
- **Developed during:** Mid-Semester – Year 2  
- **Duration:** Approximately 5 weeks  
- **Course:** Frontend Design  
- **Project Type:** Midterm Project  

---

## 📌 Project Overview

This project is a personal CV website built entirely with pure HTML, CSS, and a bit of vanilla JavaScript.  
It was created as my first frontend project to practice core web development fundamentals without using any frameworks or libraries.

The design focuses on presenting my personal information, skills, projects, and contact links in a clear and responsive layout.

---

## 🚀 Key Features

- Pure static website without frontend frameworks
- Semantic HTML structure
- Styled with CSS and responsive design patterns
- Basic JavaScript for simple interactivity
- Navigation links to different sections
- Highlights personal profile and portfolio

---

## 🛠 Technologies Used

- **HTML5**
- **CSS3** (Flexbox, positioning, responsive layout)
- **Vanilla JavaScript**

---

## 🧠 What I Learned

This project helped me:

- Understand semantic HTML and page structure
- Practice CSS layout techniques (Flexbox & responsive design)
- Add basic interactivity with DOM manipulation
- Build a real website from scratch
- Gain confidence in frontend fundamentals

Even though this site is simple, it laid the foundation for more advanced projects later.
